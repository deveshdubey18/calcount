# CalCount 🥗📱
CalCount is an Android application that helps users track calories and nutritional values of food items.

The app uses the Nutritionix API to fetch real-time nutrition data and provides a simple, fast, and privacy-focused experience.

---

## ✨ Features
- Search food items and get calorie information
- Shows nutrients like protein, carbs, fats, etc.
- Fast API based results
- Clean and simple UI
- Data stored locally using SharedPreferences
- No external database → better user privacy

---

## 🛠 Tech Stack
- Java
- Android Studio
- Android SDK
- REST API integration
- SharedPreferences for local storage

---

## 🌐 API Used
- Nutritionix API for nutrition and calorie data.
